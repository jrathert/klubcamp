# Development workflow

This project uses Spec-Driven Development.

- Project context is maintained in specs/.
- Every non-trivial feature requires a specification.
- Review requirements, plan, and validation criteria
  before implementation.
- Do not implement changes during specification.
- Implement only the approved scope.
- Run relevant tests and report validation results.
- Keep specifications synchronized with the code.
- For new or changed UI, review specs/ui-conventions.md,
  reference it in the feature specification, and validate
  consistency with other implemented views.

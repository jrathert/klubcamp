# Mission

## Purpose

Klubcamp is a responsive web application for organizing events at our field hockey club, primarily week-long training camps for young players.

It replaces fragmented announcements and paper/PDF or Google Forms registrations followed by manual Excel entry with a shared event and registration process.

## Users

- **Trainers and club officials:** create and publish events.
- **Parents:** find events and register their children.
- **Club office:** view participants per event and export registrations to Excel.

Children need not be club members to participate.

## First-release scope

- Create and publish events held at our club premises.
- Allow parents to select an event and register a child.
- Confirm successful registration by email, without an approval workflow.
- Provide per-event participant overviews and Excel export.
- Support use on mobile and desktop devices.

## Success criteria

- A trainer can set up and publish an event in under 10 minutes.
- A parent can register a child for a selected event in under 3 minutes.
- Office staff can reach an event's participant overview within a few clicks.

## Boundaries

The first release serves only our club and its on-site events. It excludes payments, registration approval workflows, and member-database integration.

The longer-term vision is to support all event administration, including payments; this does not expand first-release scope.
